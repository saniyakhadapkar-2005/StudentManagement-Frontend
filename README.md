# Student Management System - Frontend

A modern Angular-based frontend application for managing student records. The application communicates with a Spring Boot backend using REST APIs.

## Features

* View all students
* Add new students
* Update student details
* Delete student records
* Responsive UI
* REST API Integration

## Tech Stack

* Angular
* TypeScript
* HTML
* CSS
* Bootstrap
* REST API

## Backend Repository

Spring Boot + MySQL Backend
